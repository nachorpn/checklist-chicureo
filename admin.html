Gestark ya no utiliza las cuentas locales de usuarios.js.

Gestión de usuarios

Durante esta transición, la creación de cuentas, los restablecimientos y las bajas se hacen desde las consolas oficiales. No se pueden crear usuarios seguros de Authentication directamente desde una página pública de GitHub Pages sin un servicio administrativo protegido.

Cuentas · Authentication Perfiles · Firestore

Para suspender el acceso a los datos de Gestark, cambia active a false en el documento authorized_users/{uid}. Para una revocación más completa, deshabilita también la cuenta en Firebase Authentication.

Seguridad después de la migración

Los hashes antiguos pueden seguir accesibles en el historial público de GitHub, aunque el archivo actual haya sido limpiado. Cambia las contraseñas migradas por contraseñas fuertes y exclusivas.

Esta pantalla es transitoria. La futura administración dentro de Gestark necesitará un servicio confiable que compruebe el rol de administrador antes de crear, modificar o desactivar cuentas.
