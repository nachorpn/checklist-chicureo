Publicar cambios en otros celulares

Los usuarios nuevos funcionan de inmediato en este dispositivo. Para que también puedan iniciar sesión en otros celulares, debes subir el archivo actualizado a GitHub.

Después sube el nuevo usuarios.js a la raíz de checklist-chicureo en GitHub, reemplazando el existente. No necesitas volver a subir los otros archivos.

GitHub Pages es público: esta autenticación es solo un acceso de conveniencia, no una medida de seguridad para datos confidenciales.
