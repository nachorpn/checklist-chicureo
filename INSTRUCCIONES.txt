GESTARK — Corrección del parpadeo de acceso Firebase (2026.11.22.2)

1. En GitHub abre nachorpn/checklist-chicureo.
2. Add file > Upload files.
3. Sube SOLAMENTE gestark-auth.js (reemplaza el archivo del mismo nombre).
4. Confirma los cambios.
5. Abre Gestark en una pestaña nueva y pulsa Actualizar, o recarga forzada si persiste la versión antigua.

RESULTADO ESPERADO
Mientras Firebase verifica la sesion se muestra el icono de Gestark y «Verificando sesión segura…». Cuando comprueba la cuenta se abre Inicio. Si la sesion no existe o falla la verificacion, aparece el inicio de sesion anterior. Hay un boton para entrar con usuario anterior mientras se verifica.

NO se modifican los modulos, usuarios, reglas Firestore ni datos locales.
