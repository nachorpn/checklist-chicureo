GESTARK · Actualización de Solicitud de agua y Registro de traslados

CONTENIDO
- index.html: nuevo acceso a Registro de traslados visible solo al usuario SCMN (Stephanie). Conserva el acceso al calendario.
- repositorio.html: Solicitud de agua abre en pestaña/navegador externo; agrega Copiar enlace como respaldo. Conserva Registro de IND.
- traslados.html: muestra Microsoft Forms dentro de Gestark para SCMN, con respaldo de apertura externa si Microsoft impide incrustarlo.
- calendario.html + imagenes-calendario/: calendario anterior conservado e incluido por si aún no se había instalado.
- gestark-updates.js y gestark-version.json: marca de versión para detectar novedades.

SUBIR A GITHUB
Descomprimir el ZIP. Subir todos los archivos y la carpeta imagenes-calendario a la raíz del repositorio checklist-chicureo. Sobrescribir los archivos que GitHub solicite reemplazar. Confirmar con Commit changes.

LIMITACIONES
1. En iPhone/Android no existe una forma 100% garantizada desde HTML de obligar al sistema a abrir Safari/Chrome en vez de un navegador integrado. El enlace se lanza en nueva pestaña; si el sistema lo intercepta, usa Copiar enlace.
2. Microsoft Forms puede bloquear la visualización en iframe según permisos, cookies y cabeceras de seguridad. En ese caso utiliza Abrir formulario en navegador.
3. La visibilidad del acceso solo para SCMN es local en JavaScript, no permisos reales de servidor. No protege por sí sola el formulario ni oculta su URL a quien inspeccione el HTML público. Los accesos reales deben controlarse en Microsoft Forms.
4. No se ha tocado la administración, checklist ni el resto de módulos del sitio.
