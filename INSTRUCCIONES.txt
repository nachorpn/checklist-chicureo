No incluye el piloto Firebase descartado.

QUÉ CAMBIA
1. Inicio: acceso «Mis transferencias» en el PRIMER LUGAR de las herramientas, visible solo para la sesión CIBC.
2. notas-transferencias.html: anotar nombre y monto, lista pendiente, total, copiar filas como tabla para Excel y compartir texto por WhatsApp.
3. El registro es local (localStorage). Permanece aunque cierre Gestark o cambie de día, pero no sincroniza entre dispositivos y puede perderse si se borran datos del navegador. No se elimina automáticamente. Solo se vacía con confirmación tras el traspaso a Excel.
4. Conserva calendario, Repositorio, solicitud externa de agua, traslados SCMN, checklist y cobranza previos.

INSTALACIÓN EN GITHUB PAGES
- Descomprime este ZIP.
- En la raíz de github.com/nachorpn/checklist-chicureo, selecciona «Add file → Upload files».
- Sube los archivos y la carpeta imagenes-calendario sin perder su estructura.
- Confirma «Commit changes» en la rama publicada.
- Recarga Gestark, inicia sesión como CIBC y abre «Mis transferencias».

ADVERTENCIAS
- GitHub Pages es público. El acceso oculto por usuario es solo una restricción visual de frontend, no seguridad de servidor. El contenido de la libreta se almacena en el dispositivo, no en GitHub.
- No usar esta libreta como único respaldo de transferencias hasta haberlas traspasado a la planilla oficial.
- Compartir por WhatsApp abre un mensaje prellenado que el usuario debe escoger y enviar manualmente.
- La copia para Excel contiene exactamente DOS columnas separadas por tabulacion y SIN encabezados: Nombre y Monto (numero entero, sin $ ni puntos). Cada transferencia ocupa una fila. Seleccionar primera celda vacia de Nombre en Excel y pegar; si es posible, usar Pegar valores para preservar el formato. Esta funcion depende del pegado de texto tabulado que soporte Excel movil.
