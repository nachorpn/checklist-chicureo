GESTARK / GREENBOX - ENTREGAS CONTINGENTES (FASE 1)
Versión 2026.11.21.18

IMPLEMENTADO
- Hoja A4 con 3 comprobantes por página. Diseño Gestark / Greenbox, O.F. destacada, receptor, RUT, motivo, punto de entrega, responsable, firma e ID único completo.
- Sin textos de "sello de fidelidad" ni QR. No se emite ningún certificado externo.
- Firma en bloque blanco ampliado; declaración "Recibo conforme" encima de la firma en la aplicación y en el PDF.
- Eliminado el mensaje anterior sobre la firma como prueba de identidad.
- Cola temporal de PDF: tras confirmar una entrega, el comprobante firmado queda en memoria; pulsa Nueva orden para añadir otras entregas, y luego Descargar PDF para imprimir hasta 3 en cada hoja A4.
- Las firmas, nombres y RUT no se guardan en el historial persistente. Si se cierra o recarga Gestark antes de descargar, se pierde la cola temporal y no se puede reconstruir la firma desde el historial.
- No se modificó el motor del escáner, Laboratorio, Checklist, ni los demás módulos.

INSTALACIÓN
1. Descomprime el ZIP.
2. En el repositorio GitHub nachorpn/checklist-chicureo, sube SOLO los cinco archivos de este ZIP a la RAÍZ, reemplazando los homónimos.
3. Confirma Commit changes y pulsa Actualizar en Gestark.
4. Abre Entregas contingentes. Con datos FICTICIOS, confirma tres entregas y descarga el PDF: debe ocupar una hoja A4.

IMPORTANTE
La confirmación de entrega exige la acción expresa del operador y la firma del receptor. Escanear por sí solo no confirma una entrega. El PDF representa un registro interno pendiente de regularización, no una validación contra el sistema central.
La app sigue usando almacenamiento local sin seguridad de servidor; no uses RUT, firmas ni otros datos reales hasta disponer de autorización y controles corporativos adecuados.
